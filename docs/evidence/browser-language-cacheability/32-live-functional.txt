## Public hostname (idaholegalaid.org) via Cloudflare
curl -A "<Chrome UA>" https://idaholegalaid.org/  -> HTTP/2 403
Cloudflare returns 403 to scripted HTTP clients on the public hostname
regardless of User-Agent; the block is TLS/HTTP2-fingerprint based, not
UA-based. This is PRE-EXISTING and by design (validation doc 8.8), and is
why 8.9B specifies probing the Pantheon platform hostname instead.
Real browsers are unaffected. Public-hostname verification therefore has to
be done in a browser, not by curl.
